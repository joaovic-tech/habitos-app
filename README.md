# 🦷 App de Rastreamento de Hábitos Bucais - UNISAGRADO

Aplicativo mobile desenvolvido para auxiliar pacientes e a comunidade acadêmica da **UNISAGRADO – Centro Universitário Sagrado Coração (Bauru/SP)** no rastreamento e controle de hábitos bucais parafuncionais, como bruxismo, mordida de objetos, entre outros.

---

## 📌 Objetivo do Projeto

- Substituir métodos tradicionais de controle de hábitos por um **aplicativo interativo**.
- Auxiliar a **Universidade de Odontologia da UNISAGRADO** na **coleta de dados para estudos acadêmicos**.
- Proporcionar aos usuários **dicas e conteúdos educativos** sobre saúde bucal.
- Permitir o envio de **relatórios anônimos ou identificados**.
- Facilitar o acompanhamento da **evolução dos hábitos ao longo do tempo**.

## Requisitos do Sistema

| RF   | RNF   | Descrição                                                                 |
|------|-------|---------------------------------------------------------------------------|
| RF01 |       | O sistema deve permitir login via conta Google (usando Firebase Authentication). |
| RF02 |       | O usuário deve poder registrar hábitos bucais com uma intensidade (leve, médio, forte). |
| RF03 |       | O app deve apresentar dicas e conteúdos educativos sobre saúde bucal.     |
| RF04 |       | O sistema deve permitir configurar notificações personalizadas como lembrete de hábitos. |
| RF05 |       | O usuário deve ter a opção de enviar respostas anonimamente ou com identificação. |
| RF06 |       | O app deve exibir o histórico de hábitos do usuário por dia e intensidade. |
| RF07 |       | O sistema deve oferecer gráficos com estatísticas sobre os hábitos registrados. |
| RF08 |       | Deve haver uma tela de perfil com dados do usuário (quando identificado). |
|      | RNF01 | O sistema deve ser desenvolvido com React Native e suportar Android e iOS. |
|      | RNF02 | O sistema deve utilizar TypeScript para garantir segurança na tipagem.     |
|      | RNF03 | O aplicativo deve funcionar offline com armazenamento local (AsyncStorage). |
|      | RNF04 | A performance deve ser otimizada para dispositivos de entrada/intermediários. |
|      | RNF05 | A interface deve seguir princípios de acessibilidade (contraste, legibilidade, tamanho de fonte). |
|      | RNF06 | A estrutura do projeto deve seguir arquitetura modular e reutilizável.     |
|      | RNF07 | O sistema deve garantir responsividade em diferentes tamanhos de tela.     |
|      | RNF08 | As notificações devem ser configuráveis e persistentes.                    |
